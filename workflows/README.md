# Workflows

Each file here is a Markdown SOP the agent follows. Suggested sections:

- **Objective** — what this workflow produces
- **Inputs** — what's needed before starting
- **Tools** — which scripts in `tools/` to run, in order
- **Outputs** — where the deliverable ends up (usually a cloud service)
- **Edge cases & lessons learned** — rate limits, quirks, failure fixes
