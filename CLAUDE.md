# Data Intelligence Agent - VOTRE VERSION

## Vue d'ensemble
Système automatisé qui ingère des données désorganisées (CSV, Excel, databases), les nettoie, les analyse avec Claude AI pour extraire des insights, et génère des dashboards + rapports automatiques.

## Votre cas d'usage
- **Problème**: Les PME tech ont des données partout et ne savent pas les interpréter
- **Solution**: Un agent qui comprend AUTOMATIQUEMENT les données et crée des rapports intelligents
- **Bénéfice**: Temps gagné + insights exploitables

## Les 4 Agents

### Agent 1: Data Ingestion
Récupère les données de multiples sources et les standardise.

**Sources supportées**:
- CSV files
- Excel files (.xlsx)
- Databases (SQLite, PostgreSQL)
- APIs gratuites (exemple: API météo, crypto prices)
- Google Sheets (optionnel)

**Process**:
1. Scanne les fichiers/sources
2. Extrait les données
3. Unifie les formats (tout en pandas DataFrame)
4. Output: Données brutes structurées en JSON

**Example Output**:
```json
{
  "source": "sales_data.csv",
  "rows": 1500,
  "columns": ["date", "product", "revenue", "region"],
  "data_types": {"date": "datetime", "revenue": "float"}
}
```

---

### Agent 2: Data Cleaner
Nettoie et organise les données chaos.

**Fonctionnalités**:
1. **Détecte et corrige**:
   - Doublons
   - Valeurs manquantes
   - Erreurs de format/type
   - Outliers (données bizarres)

2. **Unifie**:
   - Format des dates (toutes en ISO)
   - Noms des colonnes (camelCase)
   - Unités (€ vs dollars, kg vs lbs)
   - Encodages (UTF-8)

3. **Catégorise**:
   - Identifie les colonnes numériques vs texte
   - Détecte les colonnes clés (ID, dates, montants)
   - Suggère des groupements

**Output**: Données propres + Rapport de nettoyage
```json
{
  "cleaned": true,
  "rows_before": 1500,
  "rows_after": 1485,
  "issues_fixed": {
    "duplicates_removed": 15,
    "null_values_filled": 45,
    "format_errors_fixed": 8
  },
  "quality_score": 0.95
}
```

---

### Agent 3: Data Analyst (avec Claude AI)
**C'EST L'AGENT MAGIQUE** - Il COMPREND vos données.

**Utilise Claude pour**:
1. **Analyser**: "Qu'est-ce que montrent ces chiffres?"
2. **Interpréter**: "Pourquoi est-ce que les ventes montent en janvier?"
3. **Prédire**: "Tendance future?"
4. **Recommander**: "Qu'est-ce qu'il faut faire?"

**Exemple**:
- Input: Données de ventes sur 12 mois
- Claude analyse: "Vous avez une baisse de 23% en décembre. C'est saisonnier? Problème produit? Problème marketing?"
- Output: Insights + 3 recommandations actionnables

**Process**:
1. Résume les données clés (stats de base)
2. Envoie à Claude avec context
3. Claude génère insights
4. Format en rapport lisible

---

### Agent 4: Dashboard + Report Generator
Crée les visuels et rapports.

**Génère**:
1. **Dashboard HTML** (interactif):
   - Graphiques (barres, lignes, camemberts)
   - Stat cards (KPIs principaux)
   - Tableaux de données
   - Filtres si possible

2. **Rapport automatique** (HTML):
   - Executive Summary
   - Données clés + graphiques
   - Insights de Claude
   - Recommandations
   - Signature de l'agent + date

3. **Export options**:
   - HTML (pour web)
   - PDF (pour impression/email)
   - CSV (pour autre analyse)

**Exemple rapport**:
```
DATA INTELLIGENCE REPORT - Ventes Q3 2024
Generated: 2024-10-10 by DataBot

📊 SUMMARY
- Total revenue: €145,000
- Growth: +18% vs Q2
- Top product: "Premium Plan" (42% revenue)

1. Mobile traffic driving 60% of conversions
2. European market growing 3x faster than US
3. Customer lifetime value increased 25%

✅ RECOMMENDATIONS
1. Focus marketing on mobile (ROI 3.2x)
2. Expand European team
3. Launch premium tier upgrade campaign

---
Generated by Data Intelligence Agent
```

## Métriques de succès

Track ces KPIs:
- ✅ Données ingérées par jour
- ✅ Taux de nettoyage (qualité avant/après)
- ✅ Temps de génération d'un rapport (target: < 2 min)
- ✅ Utilité des insights Claude (qualité subjective)
- ✅ Temps économisé pour l'utilisateur (estimation)

---

## Code Style

- Une fonction par agent (run())
- Type hints PARTOUT
- Logging (pas de print)
- Error handling robuste
- Docstrings détaillées
- Tests avant lancer

---

## Anti-patterns (NE JAMAIS FAIRE)

❌ Hardcoder les chemins de fichiers
❌ Pas de error handling (si un fichier manque, crash)
❌ Données hardcodées au lieu de les lire
❌ Pas de logging (comment debug?)
❌ Générer des rapports sans les sauvegarder
❌ Ne pas vérifier la qualité des données
❌ Oublier de gérer les encodages (CSV peut être Latin1 ou UTF-8)
❌ Hardcoder les clés API

## Exemple d'utilisation

**User dit**:
"J'ai un dossier avec 5 fichiers Excel sales_data, il est complètement chaotique. Comprends-moi ce qui se passe et crée un rapport."

**Le système**:
1. Agent 1 lit les 5 fichiers
2. Agent 2 les nettoie (corrige doublons, dates, etc)
3. Agent 3 demande à Claude "Explique-moi en 3 points ce qui se passe"
4. Agent 4 crée un joli HTML avec graphiques + insights
5. User reçoit un rapport clique-bouton prêt à lire

## Implémentation (état actuel du code)

```
main.py                     orchestrateur (run_pipeline, --run-all, --schedule, --no-claude)
config.py                   Settings chargés depuis .env + setup du logging
agents/ingestion.py         Agent 1 - run(settings) -> list[IngestedDataset]
agents/cleaner.py           Agent 2 - run(datasets, settings) -> list[CleanedDataset]
agents/analyst.py           Agent 3 - run(cleaned, settings) -> list[AnalysisResult]
agents/report_generator.py  Agent 4 - run(cleaned, analyses, settings) -> list[GeneratedReport]
agents/common.py            dataclasses partagées + parsing (nombres, dates, camelCase)
templates/*.j2              dashboard + rapport HTML (Jinja2, Chart.js via CDN)
scripts/generate_sample_data.py   génère data/raw/sample_sales_data.csv (données chaos)
tests/test_pipeline.py      tests (Claude mocké) : python -m pytest -q
```

- Modèle et effort de l'Agent 3 : `ANALYST_MODEL` / `ANALYST_EFFORT` (pas `CLAUDE_*`, déjà utilisé par Claude Code).
- Sans clé API valide, l'Agent 3 produit des insights statistiques et le rapport l'indique.
- Les lignes `qualityFlag=inconsistent` restent dans le CSV nettoyé mais sont exclues des chiffres.
